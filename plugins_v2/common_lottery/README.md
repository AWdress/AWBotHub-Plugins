# 通用抽奖

使用平台中的 Telegram 用户账号参与抽奖，保留原有 Lottery8Bot 抽奖支持。

## 色花堂关键词抽奖

支持真实 `@http_code_402_bot`、`@sehuatang` Bot 发言，以及官方 `@sehuatang` / `@sehuatang1` 频道的直接公告。普通用户复制、转发或只在正文中提及 Bot 的消息不会触发。

收到“群内发送关键词参与抽奖”格式的进行中活动后，读取“关键词”原文。例如本次样本会向 `@sehuatang2` 群发送：

```text
98堂永久地址 www.98t.la
```

关键词中的空格和网址保持不变，不附加复制提示或其他字符。只使用公告“群组／参与方式”字段中一致的参与群链接；不要求加入领奖联系人、宣传频道或页脚链接。参与目标固定核验为官方 `@sehuatang2` 群。

沿用“参与前最短／最长等待”进行随机等待。发送前重新读取原公告，已开奖、取消、中奖名单非空、关键词或目标变化、公告被删除时不发送。通知“参与口令已发送”不代表 Bot 已确认报名成功。

“监听群组”留空时监听全部；也可勾选公告来源频道或实际参与群。只有已收到的可信公告触发，不抓取历史活动。需参与群成员身份；未加入时，只有开启“自动加入要求的群/频道”才会尝试加群，默认不会自动加入。

新格式按账号、原消息及活动身份持久防重，编辑、频道/群重复公告及插件重启不会自动补发；发送超时或异常也不重试，请自行在群内核对。等待任务由平台托管，停用插件即停止待发送任务。普通旧格式仍按原有流程运行。
