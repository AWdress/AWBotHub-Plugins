# AI 助手

通过平台统一 AI 提供人形对话、主动搭话、`/ai` 图文解释和 `/生图`。

## 参考图生图

两种用法任选其一：

- 回复一张图片，发送 `/生图 保持人物和构图，改成水彩风格`。
- 发送图片时，在图片说明中填写 `/生图 把背景改成雪山，其他保持不变`。

`/draw`、`.draw` 和 `.生图` 同样支持。只使用本条命令携带或明确回复的那张图片，不会自动收集聊天中的其他图片。仅支持用户账号自己发送的生图命令，不会因群友发图而自动调用。

不需要额外填写接口和密钥，继续使用平台分配给本插件的生图服务、模型、代理和权限。模型及服务必须支持 OpenAI 兼容的 [`/images/edits` 图片编辑接口](https://developers.openai.com/api/docs/guides/image-generation#edit-images)。仅支持文字生图的模型不能使用参考图；接口不支持时会明确提示，不会悄悄忽略参考图改成文字生图。

支持 JPG、PNG、WebP 和 GIF，原图不超过 12MB、3200 万像素。自动校正方向、等比缩小至最长边 2048 像素、移除 EXIF 等元数据后上传；透明背景保留，GIF 使用第一帧。参考图在内存中处理，不另外落盘，但会发送给平台所配置的 AI 服务。带图命令的原图消息会保留，生成结果回复到参考图。

下载、验证或生图失败均不会自动重复生成，避免重复计费。未带参考图的 `/生图 画面描述` 仍走平台原有文字生图流程。

## 回复格式

「回复格式」中的原生富文本默认开启。Telegram Premium 用户优先使用原生富文本；非会员或账号原生能力不可用时，由平台自动降级为可读文字。关闭开关后使用普通 Telegram 消息，不影响 AI 路由和原有功能。

支持 Markdown 粗体、斜体、引用、行内代码、代码块、表格和链接。表格降级时仍保留字段与内容；链接保留完整网址，避免降级后丢失来源地址。原始 HTML 不作为标签执行。

普通对话／主动搭话与 `/ai` 解释可分别自定义回复模板：

- `{answer}`：AI 回答，模板中应保留此项。
- `{question}`：用户的问题或被解释内容。

例如：

```text
**问题**
> {question}

**回答**
{answer}
```

回复较长时自动分段，保留代码和表格内容。网络错误导致投递结果不明确时，不自动重发，避免重复回复。`/ai` 的分段回答仍在 60 秒后自动删除。

## 来源说明

本版本不新增联网搜索接口，不独立配置、保存或展示 AI 密钥。参考图适配器在请求时通过平台绑定的插件身份校验生图权限，使用该授权路由发送一次图片编辑请求，不修改平台源码。回答中的链接只是原文引用，不表示插件已经联网搜索或核验；插件不会自动补造搜索来源。

## 升级

原有配置和对话历史保留。新增的格式开关及模板默认值会在 Vue 配置页显示；保存后生效，无需重新填写原有设置。
