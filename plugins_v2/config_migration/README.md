# 平台迁移助手

通过旧平台的“平台迁移助手”，将系统设置、插件配置、启用状态、账号范围和 Bot 路由导入 AWBotHub。

- 读取后先显示脱敏预览。
- 每次成功读取后自动接收并保存旧平台新生成的一次性迁移码，可以连续执行迁移。
- 连接参数和新迁移码由后端直接保存，不会在预览与确认之间重载插件或丢失待迁移数据。
- 执行前自动备份当前平台的 `config.json`。
- 默认仅填充当前平台空值，不覆盖已有有效配置。
- “启用状态”默认不迁移，避免尚未安装的插件被自动启用。
- 系统连接参数迁移后需要重启当前平台。

建议两端位于可信内网或使用 HTTPS。迁移完成后请停用或卸载旧平台的迁移源。
