# SSD助手

使用平台所选 **Telegram 用户账号**，监听两个内置 SSD 群（`-1002014253433`、`-1001173590111`）的官方机器人 `752250569`。账号需要已加入相应群组；无需配置 Bot Token，也不需要安装多站点转账插件。

## 自动参与抽奖

开启“自动参与 SSD 抽奖”并保存。识别 `🎁 昵称的抽奖`、8 位抽奖 ID、奖品、开奖与参与区，以及 `发送口令「test」参与` 的官方消息，在所设范围内随机等待后发送原始口令。默认最短 2 秒、最长 5 秒，可分别设为 0～60 秒，最短不得大于最长。

**口令发送一次后即结束**，不跟踪开奖或中奖、不自动领奖；只保留防重记录，避免人数更新后再次发送。

- 新消息和编辑消息均可识别，人数更新、重复消息、插件重启按群组和抽奖 ID 防重复。
- 已开奖、已取消、结束及超过 72 小时的消息不参与；不回查或批量补发历史。
- 不给口令加零宽字符。以 `/` 开头或形似 `+金额`、`+下限-上限` 转账请求的口令直接跳过，避免执行其他机器人命令。
- 记录中的“口令已发送”不等于参与成功或中奖，实际结果以 SSD 官方机器人为准。

## 本人转账自动确认

从“多站点转账”移入此插件，提供“关闭／仅确认本次／确认并允许五分钟免确认”。**默认关闭，不自动导入旧开关**；更新后需要在 SSD 助手选择确认方式并保存。五分钟模式可能使后续转账不再弹出确认，请确认理解后开启。

只确认官方机器人回复本人原始 `+金额` 或 `+下限-上限` 请求的消息，核对回复目标与金额；随机转账需要官方提示明确的实际转出额，且不得超出原范围。不会代你发起转账，不点击 URL、取消按钮或别人的确认消息。

同一原始请求只尝试确认一次。先持久登记再点击，点击超时、停用或意外中断时不自动重试，防止重复操作。异常时请在群里核对官方回执后手动处理，不要删除防重记录。

“多站点转账”仍独立记录成功回执、致谢及发送排行榜；**从 2.0.12 起不再确认 SSD 转账**，旧 `ssd_click_mode` 配置也不执行点击。

## 设置与运行记录

Vue 配置页按抽奖、转账确认、操作记录分组。所有自动功能默认关闭；有明确可见的延迟默认值和风险提示。只监听消息，不创建定时轮询任务，也不会每分钟空跑。

操作记录最多展示最近 100 条，防重记录保留 90 天。发送或点击异常只记录“结果未确认”，不会把调用成功误报为抽奖参与成功或转账成功。防重存储不可用时不发送、不点击。
