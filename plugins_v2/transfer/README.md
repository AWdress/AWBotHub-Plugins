# 多站点转账

监听内置 PT 站点群的转账机器人，记录与本账号有关的转入、转出，并生成排行榜。

## SSD 转账记录

SSD 转账自动确认已移至独立的「SSD 助手」。本插件只监听转账结果、记录金额、发送致谢和生成排行榜，不再点击确认按钮；旧配置中的自动确认选项也不再执行。需要自动确认时，请安装并启用 SSD 助手的相应功能。

- 仅记录已启用 SSD 站点中，与本账号有关且可核实原始请求的转账。
- 仍会读取“请确认转账”“转账金额较大”等确认提示，缓存实际转出金额及请求关联，但不会点击按钮，也不会将提示计入排行榜。
- 无论由你手动确认还是 SSD 助手自动确认，都必须等机器人明确返回转账成功，才会记录金额、发送致谢和更新排行榜。
- SSD 官方机器人回复本账号相关的 `+1` 请求时，也支持以 `💸` 开头的简短成功回执，例如 `💸 yue`、`💸 ++`、`💸 真抠`。金额仍取原始请求；其他站点和其他金额不使用此简短回执规则。
- 回执与转账口令读取 Telegram 无格式原文，加粗等消息格式不影响匹配。
- 待确认、预计税费、预计到账、取消和未知状态均不会计入排行榜。
- SSD 成功流水按站点、本账号、群组和原始 `+金额` 请求的消息 ID 持久去重。延迟编辑、另发成功回执或重启后不会重复入账；可明确关联的同额不同请求仍各记一笔。回执缺少可核实的原始请求 ID 时保守跳过。

### 随机金额口令

支持 `+1-100`、`+666-667` 等范围口令的实际金额记账；是否自动确认由 SSD 助手控制。

- 从官方确认页的“转出金额”或完整成功回执读取实际金额；例如 `+1-100` 实际转出 24，就按 24 记账。
- `+666-667` 确认页选中 667 时，成功后按 667 入榜，不记录 66.70 税费或 600.30 到账额。
- 确认提示本身不入榜，必须收到明确的成功回执。实际金额必须在口令范围内，且不能与已经确认的金额冲突。
- 无法取得实际金额时不猜上下限；无法唯一关联原请求时不记账。
- 保留独立成功回执关联、重启恢复和原请求防重复逻辑，转入和转出均按实际金额统计。

### 删除确认后另发回执

支持机器人删除确认提示后另发“转账完成”消息，不要求成功消息仍回复原提示。五分钟内免确认的转账也会监听原始 `+金额` 请求。

- 原始请求和确认提示的关联保留 30 分钟，并持久保存；由你手动点击或 SSD 助手确认均可关联。
- 独立回执按同群、双方真实 Telegram 账号及转账金额匹配，不用昵称或单独的金额猜测。公开用户名链接会向 Telegram 核实账号。
- 回执仍指向已删除的确认提示时，可按提示 ID 找回原请求。完全独立的回执必须带可核实的双方账号链接。
- 同一群、同一双方、同一金额有多个候选且回执没有明确回复关系时，不猜测、不入榜，日志会提示无法唯一关联。
- 无法关联或发送失败会记录日志；升级前已经错过的转账不会自动扫描历史、补记或重发。

升级不会清空旧榜单。旧版误记流水缺少足够的原始交易依据，无法安全自动删除；请在排行榜管理中核对后处理。

持久来源去重仅适用于可关联原始请求的 SSD/plus 流水；HDSky 广播等其他站点保留既有回执去重方式。
