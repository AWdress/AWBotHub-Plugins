# 多站点转账

监听内置 PT 站点群的转账机器人，记录与本账号有关的转入、转出，并生成排行榜。

## SSD 大额转账

在配置页的 SSD 自动确认中，可选择关闭、仅确认本次，或确认并在五分钟内不再提醒。默认关闭。

- 自动确认仅处理已启用 SSD 站点中，官方机器人回复本账号 `+金额` 请求的确认消息。
- 支持新版“请确认转账”“转账金额较大”提示；按按钮文字选择，不按固定位置猜测，不点击取消或链接按钮。
- 点击确认只是提交操作，仍要等机器人明确返回转账成功，才会记录金额、发送致谢和更新排行榜。
- 待确认、预计税费、预计到账、取消和未知状态均不会计入排行榜。
- 同一条确认提示在当前插件运行期间只自动提交一次；超时不会自动重复点击。
- SSD 成功流水按站点、本账号、群组和原始 `+金额` 请求的消息 ID 持久去重。延迟编辑、另发成功回执或重启后不会重复入账；同额但不同请求仍各记一笔。回执缺少可核实的原始请求 ID 时保守跳过。

升级不会清空旧榜单。旧版误记流水缺少足够的原始交易依据，无法安全自动删除；请在排行榜管理中核对后处理。

持久来源去重仅适用于可关联原始请求的 SSD/plus 流水；HDSky 广播等其他站点保留既有回执去重方式。
