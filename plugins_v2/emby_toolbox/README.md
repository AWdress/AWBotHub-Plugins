# Emby 工具箱：字段保护与旧误锁修复

## 2.1.7 的锁定规则

别名仅保护 `SortName`，国家／语言标签仅保护 `Tags`，Genre 维护仅保护
`Genres`，季名仅保护 `Name`。季集编号修复不再整体锁定条目，也不向
`LockedFields` 填入未经确认的季集编号字段。

“连接与策略 → 仅锁定本次修改的字段”默认开启。旧 `fix_lock_data` 开关仅
迁移为字段保护选项，不会被解释为开启整体锁。关闭字段保护不删除原字段锁。

日常维护保留原有整体锁；原本未整体锁定的项目不会因字段维护而整体锁定。
读取不到可靠锁状态时停止该次写入，不猜测、不解锁。

## 已经整体锁定的项目如何处理

升级不会自动解除历史锁。旧版没有记录修改前的整体锁状态，无法仅凭
`LockedFields` 或别名缓存准确区分插件误锁与人工锁定。

1. 建议先备份 Emby 数据库及媒体旁的 NFO。
2. 在“误锁修复”中填入**你已核对受影响的条目 ID**，可用逗号、空格或换行
   分隔，一次最多 500 个不同 ID。此操作不按“媒体库名称”筛选，也不自动
   扫描全库猜测误锁。
3. 如需处理继承锁，可勾选检查指定剧集／季的下级。只纳入能确认父子关系、
   已整体锁定且 `LockedFields` 为空的季／单集。带字段锁的下级不会被连带
   解锁；需要处理时请单独明确填写其 ID。
   若上一批中途停止，父级已解锁但仍有残余锁定单集，可再次填写相同父级 ID
   并勾选此项重新预览，已解锁项目不会重复写入。
4. 点击“只预览，不修改”。预览完全只读，有效期为 30 分钟；最多展示前
   100 项样本，数量包含全部候选。检查范围、数量及风险后再明确确认。
5. 点击“备份并解除这些整体锁”。插件先把原锁状态持久保存到平台插件存储，
   备份失败则不写入。随后逐条重新读取，只解除状态与预览一致的整体锁，
   保留 `LockedFields`，并以回读结果统计成功。
6. 下载最近一次备份另存后再操作下一批。平台内仅保留最近一批的锁状态备份，
   不含 API Key、授权信息或完整媒体元数据。该备份供核对锁状态，并非媒体库
   数据库备份，也不是自动回滚文件。

预览遇到重复页、总数变化、缺少完整分页信息、未知锁状态或读取失败时，不
生成可执行计划。执行时发生锁状态／字段锁／父子关系变化的项目会跳过；写入
超时或回读失败记为失败，不盲目重试。重新执行必须重新预览。

修复工具不主动调用元数据刷新、不直接修改磁盘 NFO，也不删除字段保护。
Emby 自身是否同步保存 NFO 由其元数据保存器设置决定。旧 NFO 中的
`<lockdata>true</lockdata>` 仍需核对，避免之后重扫又导入整体锁；不要未经
备份直接对所有 NFO 批量替换。解除整体锁后，缺失标题、日期或图片是否
需要刷新，应在 Emby／Strm Assistant 中另行确认。
